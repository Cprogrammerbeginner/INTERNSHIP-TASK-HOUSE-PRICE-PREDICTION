# House Price Prediction

## Project Overview

This project focuses on predicting house prices using Machine Learning techniques.  
The objective is to analyze housing data, preprocess the dataset, train a regression model, and evaluate prediction performance.

The project was implemented using Python in Google Colab/Jupyter Notebook.

---

## Dataset Information

The dataset contains housing-related features used to predict property prices.

### Common Features:
- Square Footage
- Number of Bedrooms
- Number of Bathrooms
- Location
- House Area
- Property Price

---

## Technologies Used

- Python
- Google Colab / Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## Tasks Performed

### Data Loading
- Imported the dataset
- Displayed sample records
- Checked dataset structure

### Data Preprocessing
- Handled missing values
- Encoded categorical variables
- Selected important features
- Split data into training and testing sets

### Model Training
Implemented regression models such as:
- Linear Regression
- Gradient Boosting Regressor

### Model Evaluation
Evaluated model performance using:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score

### Data Visualization
Created visualizations including:
- Correlation Heatmap
- Actual vs Predicted Prices Graph
- Feature Distribution Plots
